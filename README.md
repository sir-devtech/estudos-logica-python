## Por que Berserk

Lógica é disciplina. Você erra, volta, ajusta o fluxo. Igual a jornada: um passo, um `if`, um loop. O tema é só o casaco — o que importa é versionar e colaborar sem bagunçar a `main`.

## Como rodar

```bash
git clone https://github.com/sir-devtech/estudos-logica-python.git
cd estudos-logica-python/code-atividades
python 01_hello_brand.py
```

Python 3. Os scripts em `novos-codigos/` entraram via PR na branch `versao_01`.

## Estrutura

```text
code-atividades/   # exercícios na main
novos-codigos/     # contribuições via PR
docs/              # GIFs
```

| Pasta | Arquivos |
